NovaPad
A lightweight, fast, and portable Windows text editor designed as a reliable alternative to the standard Notepad, built specifically for handling large files effortlessly.

Key Features:
Large File Support: Smoothly opens, views, and edits massive log files, dumps, and databases (hundreds of megabytes) that usually cause the standard Notepad to freeze or crash.

Fully Portable: Delivered as a single .exe file — no installation required, leaves no system footprint, and runs directly from any USB flash drive.

Minimalist UI: Clean, distraction-free interface with zero bloatware or ads. Optimized for speed and pure performance.

How to Download & Run:
Go to the Releases section on the right side of the repository.

Download the latest .exe binary.

Run and enjoy!(Note: Windows SmartScreen may show a prompt on the first run — click "More info" → "Run anyway", as this is an independent developer build).
